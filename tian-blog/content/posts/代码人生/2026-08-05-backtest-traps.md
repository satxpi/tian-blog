# 回测曲线漂亮得像假的？聊聊量化回测里最常见的五个坑

## 一个让我印象深刻的例子

去年有个朋友兴冲冲来找我，屏幕上是一张年化 80%、最大回撤只有 8% 的资金曲线，漂亮得像艺术品。他说策略是均线突破加动量过滤，代码跑了一周，参数调了三百多组，终于找到了"圣杯"。

我问了他三个问题：信号是用当天的收盘价算的吗？股票池里的退市股还在吗？这三百多组参数，是挑出来的还是定好的？

他愣了几秒，说：你等等，我回去看看。

三个月后他告诉我，实盘收益 -15%，曲线跟回测完全两个物种。他踩的坑，一个都没落下。

**回测不会骗人，但回测会骗你。** 它不会故意造假，但它会把你的错误放大成漂亮的曲线。今天就把量化回测里最常见的五个坑摊开聊，每一个我都踩过，希望你别再踩一遍。

## 坑一：未来函数——你偷看了明天的答案

未来函数（Look-ahead Bias）是回测里最致命、也最常见的坑，本质是：**你的信号用到了信号产生时点之后的数据。**

最经典的写法长这样：

```python
import pandas as pd

# 错误示范：用当天收盘价算信号，却假设当天开盘就买入
df['signal'] = (df['close'] > df['close'].shift(1)).astype(int)
df['position'] = df['signal'].shift(0)  # 信号当天就生效
```

收盘价是在 15:00 才确定的，你不可能在 15:00 之前按收盘价成交。正确做法是信号往后推一根K线：

```python
# 正确做法：T 日收盘算信号，T+1 日开盘执行
df['position'] = df['signal'].shift(1)
```

就这一个 `shift(1)`，能让年化差出十几个点。**凡是信号和成交之间没有隔一根K线的回测，收益都要打个问号。** 自查方法很简单：把信号往未来平移 1 根、2 根、5 根K线，如果收益几乎不衰减，说明你的信号里大概率藏着未来信息——真信号对滞后是敏感的，假信号对滞后是无所谓的。

## 坑二：幸存者偏差——死人不会说话

幸存者偏差（Survivorship Bias）说的是：**你用今天的股票池，去回测过去的历史。**

今天还活着的股票，都是过去十年没被退市、没被 ST、没暴跌到没人要的"幸存者"。那些退市的、暴雷的股票，早就不在你的数据里了。你用幸存者回测，等于默认自己过去十年每次都能精准避开所有雷——这收益率当然好看。

A 股尤其明显：壳资源时代退市率低还好，这几年退市常态化之后，**不做幸存者偏差修正的回测，年化普遍虚高 5 到 10 个点。** 修正方法只有一个笨办法：用带退市股票的历史成分股数据，或者至少用指数成分的历史快照，而不是今天的快照。

记住一句话：**回测里没有退市股，不代表你的实盘不会踩到退市股。**

## 坑三：过拟合——你调的不是参数，是运气

这是新手最容易沉迷的坑。策略效果不好？加个过滤条件。还不好？再调个参数。调着调着，回测曲线就"变好"了——但这不是策略变好了，是**你记住了训练集上的答案**。

统计学上有个残酷的事实：参数越多、尝试的组合越多，过拟合越严重。你试了 300 组参数，最优的那组在样本内必然好看，因为总有一组参数恰好"背"下了历史走势的噪声。这跟考试前背答案一样：背得再熟，换一套题就露馅。

怎么自查过拟合？两个简单方法：

**方法一：参数敏感性分析。** 把最优参数附近的参数都跑一遍，画成热力图。如果最优参数是一个孤立的"尖峰"，周围全是亏损区——恭喜你，过拟合实锤。真正的稳健策略，参数曲面应该是平缓的"高原"，参数稍微动一动，收益只是小幅波动。

```python
import numpy as np

# 参数敏感性：看最优参数周围是不是平滑的高原
results = {}
for n in range(5, 41, 5):          # 均线周期
    for k in range(1, 6):          # 突破倍数
        results[(n, k)] = backtest(n, k).sharpe

# 如果 (25, 3) 是唯一尖峰，周围全塌 → 过拟合
```

**方法二：减少参数。** 我自己的经验：一个策略的有效参数超过 3 个，就该怀疑它是不是在背答案。因子可以多，但核心参数必须少，少到你能给每个参数讲出一个"为什么"。

## 坑四：成本失真——回测赚钱，手续费亏钱

这个坑上一篇聊交易成本时提过，但回测里值得再强调一次：**很多漂亮的回测曲线，是把交易成本设成 0 或者象征性的万分之一跑出来的。**

实盘里，一次完整的交易要付出：佣金、印花税、滑点，还有冲击成本——你资金量一大，下单本身就会把价格推走。高频一点的策略，一年换手几十倍，成本直接从收益里吃掉一大块。

我的建议是回测时**成本往高了设**：单边千分之二起步，高频策略直接按千分之三到五算。宁可回测难看一点，也别让实盘给你上第一课。回测里被成本杀死的策略，不值得可惜；实盘里被成本杀死的策略，才叫冤枉。

## 坑五：样本内自嗨——把同一段历史反复用

最后一个坑最隐蔽：**你用 2016 到 2025 年的数据调参、选因子、定阈值，然后用 2016 到 2025 年的数据验证效果，然后宣布策略有效。**

这不是验证，这是自嗨。你所有的决策都基于同一段历史，验证集早就"脏"了——就像你先看了答案再考试，然后说自己考了满分。

正确的做法是**样本外测试（Out-of-Sample）和滚动前推（Walk-Forward）**：

```python
# Walk-Forward：滚动地用前 3 年调参，后 1 年验证
for end in range(2019, 2026):
    train = data[data.year < end]      # 训练：调参
    test  = data[data.year == end]     # 验证：参数固定，直接跑
    params = optimize(train)           # 只在训练集上调参
    results.append(backtest(test, params))  # 验证集绝不参与调参
```

规则就一条：**调参用的数据和验证用的数据，物理上不能有交集。** 如果你 2026 年的策略，用 2025 年之前的数据调参、2025 年之后的数据验证，还能赚钱，那才勉强算数。哪怕这样，也只代表过去——市场会变，样本外永远有新的样本外。

## 老田的观点

聊完五个坑，说点掏心窝子的。

第一，**回测的作用是证伪，不是证明。** 回测永远无法证明一个策略能赚钱——它只能帮你排除明显不行的策略。年化 80% 的回测什么都说明不了，但"连续三年样本外亏损"的回测，一定说明这个策略不行。把回测当"排除法"用，你会少踩一半的坑。

第二，**回测曲线越漂亮，越要警惕。** 真实的策略是磕磕绊绊的：有盈利的年份，有亏损的年份，有长时间不赚钱的横盘期。一条丝滑上扬、回撤极小、年年正收益的曲线，在真实市场里几乎不存在——它更可能是某个坑的产物。看到完美曲线，第一反应应该是找 bug，而不是庆祝。

第三，**回测的敌人不是市场，是你的偷懒。** 未来函数多写一个 shift 就能规避，幸存者偏差换一套数据就能解决，过拟合少调几个参数就能缓解。这些坑的修复成本都很低，唯一的成本是"承认自己可能错了"。量化这行，**对自己诚实，是最稀缺的能力。**

第四，也是最重要的：**回测过得好，不代表实盘过得好；但回测做得严谨，实盘至少不会死得不明不白。** 回测不是用来证明"我能赚钱"的，是用来证明"我至少没犯低级错误"的。把低级错误都排掉，剩下的，才是值得你拿真金白银去试的东西。

回测是量化里最诚实的一面镜子——你给它什么，它就还你什么。给它偷懒，它还你幻觉；给它严谨，它还你清醒。共勉。
