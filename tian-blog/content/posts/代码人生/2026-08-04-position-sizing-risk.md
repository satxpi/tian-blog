# 回测再牛，仓位管不好照样爆仓——聊聊量化里的仓位管理

## 两个朋友的两种结局

去年年底，我身边有两个朋友几乎同时开始做量化，策略思路都差不多：多因子选股，动量加反转，回测年化都在 25% 上下。

半年过去，结局完全不同。

朋友 A 账户曲线稳稳向上，最大回撤 12%，人逢喜事精神爽。朋友 B 呢，账户在 4 月份那一波回调里直接腰斩，现在还在回本的路上挣扎。

两个人策略几乎一样，为什么结果天差地别？

差别不在策略，在仓位。A 每次只拿总资金的 20% 押一个标的，B 恨不得满仓干，还上了杠杆。B 的策略在回测里赢过 A，但实盘里，**B 输给了自己的仓位**。

今天就把仓位管理这件事聊透。记住一句话：**策略负责赚钱，仓位负责活命。** 活不下来，赚多少都是别人的。

## 为什么仓位比选股更重要

先看一个残酷的数学事实。

亏 10%，需要涨 11.1% 回本；亏 20%，需要涨 25% 回本；亏 50%，需要涨 100% 回本；亏 80%，需要涨 400%。

**亏损是复利最大的敌人，而且它是非对称的。** 你赚 50% 再亏 50%，不是回到原点，是亏 25%。这个不对称性，决定了控制回撤的下限，比追求收益的上限重要得多。

所以仓位管理的本质，不是"怎么分配钱"，而是"怎么保证自己永远有机会玩下一局"。赌场里真正的赢家不是手气最好的，是本金最多的——仓位管理就是你的"本金保护罩"。

有人可能要问：那我分散持仓不就行了？分散是降低个股风险，但解决不了系统性风险——大盘跌的时候，你持有的 20 只股票会一起跌。**分散解决的是"踩雷"问题，仓位解决的是"活着"问题，两者都要。** 而且很多人不知道：分散持仓时，每只股票的仓位大小，本身就是一种仓位管理。

## 三种主流的仓位算法

市面上仓位管理方法很多，万变不离其宗，核心就三种思路。

### 第一种：等权分配

最简单。选 10 只股票，每只 10%。优点是好理解、好执行、天然分散；缺点是**它假设所有股票风险一样**——一只波动 2% 的银行股和一只波动 8% 的题材股各占 10%，后者实际承担的风险是前者的 4 倍。

等权适合新手起步，但绝对不是终点。

### 第二种：波动率目标（Vol Targeting）

这是机构用得最多的方法。思路是：**让每笔仓位承担的风险大致相等，而不是让金额相等。**

具体做法：

```
目标波动率 = 你愿意承受的组合年化波动（比如 15%）
个股仓位 = 目标波动率 / 该股票的年化波动率
```

波动大的股票给少一点，波动小的给多一点，让每一块钱的风险贡献趋同。这样组合的波动率被"钉"在目标附近，回撤可预期，心态不崩。

### 第三种：凯利公式

这是理论上的"最优解"。凯利公式告诉你：给定胜率和赔率，押多少比例能让长期资金增长最快。

```
f = (b × p - q) / b

其中：
p = 胜率，q = 1 - p（败率）
b = 赔率（盈亏比，赚的时候赚 b 倍，亏的时候亏 1 倍）
```

举个例子：一个策略胜率 55%，赚的时候平均赚 1.2 倍，亏的时候亏 1 倍。代入公式：

```
f = (1.2 × 0.55 - 0.45) / 1.2 = (0.66 - 0.45) / 1.2 ≈ 0.175
```

凯利建议你押 17.5% 的仓位。听起来很合理对吧？**但凯利公式有个致命前提：你的胜率和赔率必须是准确估计的。** 实盘里，参数估计必然有误差，而凯利公式对误差极其敏感——你高估一点点胜率，公式给你的仓位就可能翻倍，然后一波回撤教你做人。

所以实务界公认的做法是**半凯利甚至四分之一凯利**：把凯利算出来的仓位砍半再砍半。收益少一些，但活得久得多。凯利是数学的极致，半凯利是人的极致。

## 把仓位算法写进代码

光说理论没意思，给你一段我自己用的仓位计算代码，三种方法都有：

```python
import numpy as np

def position_size_equal(n_stocks: int, nav: float) -> float:
    """等权：每只股票分到的金额"""
    return nav / n_stocks

def position_size_vol_target(annual_vol: float, target_vol: float,
                             nav: float, vol_window: int = 60) -> float:
    """
    波动率目标：按个股年化波动率反推仓位金额。
    annual_vol: 个股年化波动率（比如 0.35 表示 35%）
    target_vol: 组合目标年化波动率（比如 0.15）
    """
    weight = target_vol / max(annual_vol, 1e-6)
    weight = min(weight, 0.5)  # 单票仓位上限 50%，防止极端值
    return nav * weight

def kelly_fraction(win_rate: float, payoff_ratio: float,
                   half_kelly: bool = True) -> float:
    """
    凯利公式。win_rate: 胜率；payoff_ratio: 盈亏比（赚 b 倍 / 亏 1 倍）。
    默认返回半凯利，实盘建议用半凯利或四分之一凯利。
    """
    q = 1.0 - win_rate
    f = (payoff_ratio * win_rate - q) / payoff_ratio
    f = max(f, 0.0)  # 期望为负时不下注
    return f * (0.5 if half_kelly else 1.0)
```

几个落地细节：

一是**波动率要用滚动窗口实时算**，不能用上市以来的一刀切波动率。市场波动率是时变的——2024 年和 2026 年，同一只股票的波动率能差出一倍。用 60 个交易日的滚动年化波动率，每周更新一次，够用。

二是**仓位要设硬上限**。不管模型算出什么，单票仓位我一般不超过 30%，组合单日最大亏损预算不超过净值的 2%。模型是死的，风险偏好是活的，别让公式替你做超出承受能力的决定。

三是**凯利公式要定期重估参数**。胜率和赔率不是恒定的，策略失效时，凯利会给出一个"自信的、错误的"大仓位。所以每季度做一次参数体检，胜率下滑就自动降仓——**仓位管理也是策略失效的第一道预警线。**

## 回撤与仓位的数学关系

再补一个特别有用的换算关系。

假设你的策略，满仓时的最大回撤是 M（比如 40%），那么你实际使用的仓位比例 w，对应的组合最大回撤大约是：

```
组合最大回撤 ≈ w × M
```

想控制最大回撤在 15% 以内，满仓回撤 40% 的策略，仓位就应该压在 37% 左右（15% / 40%）。这个线性近似在回撤不大时挺准，用来做"目标回撤 → 目标仓位"的反推非常方便。

记住这个公式，你就不会犯"策略回撤 40% 还满仓干"的错。**先定你能承受的回撤，再倒推仓位，而不是先定仓位再祈祷回撤别来。**

## 老田的观点

最后说几句掏心窝子的。

第一，**仓位管理不是策略的附属品，它就是策略的一部分。** 一个没有仓位规则的策略，等于没有刹车系统的车——发动机越好，死得越快。回测里满仓跑出来的漂亮曲线，实盘里就是你的催命符。

第二，**先定回撤底线，再谈收益目标。** 我见过太多人问"怎么年化 50%"，很少有人问"怎么保证永远不爆仓"。正确的顺序永远是：先确定你能承受的最大回撤（亏多少你会睡不着、会割肉），然后用波动率目标法反推仓位，最后才轮到选股和择时。

第三，**一致性比正确性重要。** 仓位管理的精髓不是每次都算对，而是每次都按规则来。你可以用等权起步，但必须有一个写下来的、能执行的仓位规则，并且雷打不动地执行。规则粗糙没关系，没有规则才是最大的风险。

第四，也是最重要的一条：**永远给自己留重来的机会。** 满仓、上杠杆、梭哈，这些词看着刺激，实盘里都是"一次性博弈"。而量化是重复博弈，重复博弈的赢家，一定是活得最久的那个人。

策略决定你赚多少，仓位决定你活多久。共勉。
