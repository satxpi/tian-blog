# 操作手册：截图与公众号发布

## 一、如何截图

### 方法1：浏览器截图（推荐）

```bash
# 使用browser工具截图
browser action=screenshot url=https://example.com
```

适用场景：网页截图、公众号后台操作

### 方法2：Puppeteer截图

```bash
cd /root/.openclaw/workspace
node -e "
const puppeteer = require('puppeteer');
(async () => {
  const browser = await puppeteer.launch({ headless: true });
  const page = await browser.newPage();
  await page.goto('https://example.com', { waitUntil: 'networkidle2' });
  await page.screenshot({ path: '/tmp/screenshot.png', fullPage: true });
  await browser.close();
})();
"
```


## 二、如何发表公众号文章

### 方法1：API直接发布（推荐）

```bash
cd /root/.openclaw/workspace

python3 << 'EOF'
import requests, json

# 获取token
APPID = "wx4d76a79c84e3ebbc"
SECRET = "72d4248a0d0384384884116ff2470e06"
url = f"https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid={APPID}&secret={SECRET}"
token = requests.get(url, timeout=10).json()['access_token']

# 上传封面
cover_path = "/tmp/cover.jpg"
url = f"https://api.weixin.qq.com/cgi-bin/material/add_material?access_token={token}&type=image"
with open(cover_path, 'rb') as f:
    thumb_media_id = requests.post(url, files={'media': ('cover.jpg', f, 'image/jpeg')}, timeout=30).json()['media_id']

# 创建草稿
title = "文章标题"
content = "<p>文章内容</p>"
digest = "摘要"

url = f"https://api.weixin.qq.com/cgi-bin/draft/add?access_token={token}"
article = {
    "title": title,
    "author": "虾大",
    "content": content,
    "digest": digest,
    "thumb_media_id": thumb_media_id,
    "show_cover_pic": 1,
    "need_open_comment": 0,
    "only_fans_can_comment": 0
}
data = {"articles": [article]}
json_str = json.dumps(data, ensure_ascii=False).encode('utf-8')
r = requests.post(url, data=json_str, headers={'Content-Type': 'application/json; charset=utf-8'}, timeout=30)
print(r.json())
EOF
```

```bash
p = WeChatRobustPublisher('wx4d76a79c84e3ebbc', '72d4248a0d0384384884116ff2470e06')

# 上传封面
thumb_media_id = p.upload_cover_image()  # 或自己上传

# 创建草稿

    title="标题",
    content="<p>内容</p>",
    author="虾大",
    digest="摘要",
    cover_media_id=thumb_media_id
)
print(f"草稿ID: {draft_id}")
EOF
```

## 三、重要规则

### 标题格式
- 易经系列：`闲聊易经｜01开篇：不是算命，是看变化的方法论`
- 日常文章：简洁有力，不超过10个中文字（微信按字节限制）

### 结尾格式
```
以上均为个人观点，如有错误的地方，还请海涵。

【本文由AI生成，经人工审核修改】
生成时间：2026年04月21日
```

### 禁止事项
- **绝不删草稿箱内容** — 用户自己判断删不删
- **不预告下一篇**
