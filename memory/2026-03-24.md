### [INFRA] OpenClaw 记忆方案配置

- **结论**: lossless-claw 已废弃，改用 legacy + memory-core + self-improving 三件套
- **文件变更**: 
  - skills/self-improving-agent/ (新安装)
  - .learnings/LEARNINGS.md, ERRORS.md, FEATURE_REQUESTS.md (新创建)
- **标签**: #memory #openclaw #config

#### 组件说明

| 组件 | 状态 | 作用 | 数据位置 |
|------|------|------|----------|
| legacy 引擎 | ✅ 已配置 | 上下文压缩（原 lossless-claw 核心） | ~/.openclaw/agents/main/sessions/*.jsonl |
| memory-core | ✅ 已加载 | 文件搜索（memory_search/memory_get 工具） | ~/.openclaw/memory/main.sqlite |
| self-improving | ✅ 新安装 | 自动记录错误和学习 | ~/.openclaw/workspace/.learnings/ |

#### 配置文件

- `contextEngine: legacy` 在 ~/.openclaw/openclaw.json 的 plugins.slots 中
- 不需要 OpenAI key（memory-lancedb 需要，暂时不用）

#### 使用方式

1. **legacy** - 自动运行，对话太长时压缩
2. **memory-core** - 我自动搜索 memory 文件夹
3. **self-improving** - 自动记录：
   - 命令失败 → ERRORS.md
   - 用户纠正 → LEARNINGS.md
   - 发现更好的方法 → LEARNINGS.md

#### 重要事项

- 重要信息要写进 memory/ 文件夹才能被搜索到
- legacy 不是插件，是内置引擎
- memory-lancedb 需要 OpenAI key，暂时用不了
