# 闲聊易经｜13比卦：选对人站对队，比什么都重要

师卦讲带队伍，打硬仗。仗打完了呢？

该合作了。

比卦，就是师卦的下一卦。打完了，不是各回各家，是**重新站队、重新结盟**。师卦是分，比卦是合。分是为了成事，合是为了走得远。

## 卦象：地上有水

比卦长这样：

```
上爻 ━ ━  ← 坎上阴
五爻 ━━━  ← 坎中阳（卦主）
四爻 ━ ━  ← 坎下阴
三爻 ━ ━  ← 坤上阴
二爻 ━ ━  ← 坤中阴
初爻 ━ ━  ← 坤初阴
```

上卦是坎，水。下卦是坤，地。

坤卦六个爻全是阴爻，坎卦只有中间一个阳爻。所以整个比卦**只有九五一个阳爻**，被五个阴爻包围着。

**水在地上，这就是比卦。**

师卦是水在地下，看不见的军队。比卦反过来，水在地上，润泽万物。水的特性是往低处流，跟地贴合得严丝合缝。比卦取的就是这个意象——**亲近、依附、合作**。

水不会离开地，地也不会拒绝水。这种关系，就是"比"。

但注意：比卦五爻是唯一的阳爻，四个阴爻都围着它。**一个人被所有人追随，这是好事吗？**

看后面就知道了。

## 卦辞：吉，原筮元永贞，无咎，不宁方来，后夫凶

卦辞：**比，吉。原筮元永贞，无咎。不宁方来，后夫凶。**

比，亲近、合作。合作是好事，所以"吉"。

但后面跟着一堆条件：

**"原筮元永贞"**——合作之前，要先想清楚，你的动机是不是纯正的（元），是不是能长久的（永），是不是正当的（贞）。三个条件，缺一个都不行。

很多人合作出问题，不是能力不行，是**合作之初就没想清楚为什么合作**。有人为了面子答应合作，有人因为不好意思拒绝，有人看别人都在合作就跟着合。这些都不是"元永贞"。

**"不宁方来"**——本来不安定的人，也会来找你合作。说明什么？说明你是值得信赖的，别人愿意靠过来。

**"后夫凶"**——来晚了，凶。别人都已经站好队、建好关系了，你最后才来，没人理你。

比卦在说一个很现实的道理：**合作要趁早，犹豫就错过。**

## 彖辞：亲辅也，上下顺也

彖辞说：**"比，辅也，下顺从也。"**

比就是辅助、亲近。下面的顺从上面的，上下协调，事情就能成。

彖辞里有一句特别精准：**"建万国，亲诸侯。"**

打完天下，要分封诸侯，建立联盟。不是一个人把所有事都扛了，是**把对了的人放在对了的位置上，形成合作网络**。

这就是比卦的核心：不是单打独斗，是建系统、建关系。

但彖辞也警告了：**"后夫凶"又重复了一遍。**

来晚了就是不行。机会窗口不会一直开着。

## 象传：先王以建万国，亲诸侯

象传说：**"地上有水，比。先王以建万国，亲诸侯。"**

跟彖辞呼应。古代的帝王看到水在地上流的卦象，想到的是：**分封诸侯，建立联盟体系。**

这句话放到现在，翻译过来就是：**建生态、建合作网络、建利益共同体。**

一个人能做多大，不取决于他多厉害，取决于他身边有多少靠谱的人愿意跟他一起干。

## 初爻：合作的底线——诚意

初六：**有孚比之，无咎。有孚盈缶，终来有他吉。**

有孚，就是有诚意、有信用。

比卦第一爻就说：**合作的底线是诚意。** 带着诚意去建立关系，没有问题。

后面更精彩："有孚盈缶"——诚意满得溢出罐子。这是在说，你的诚意不能只是刚好够，要**充足到让所有人都感受到**。

"终来有他吉"——最后会有意外的收获。

这爻在告诉我们：**合作不是算计，是拿出真东西来。** 你真不真诚，别人感受得到。满罐子的诚意，换来的是超出预期的回报。

## 二爻：跟对人是第一要务

六二：**比之自内，贞吉。**

从内部建立合作关系，吉。

六二是下卦的中爻，位置正，跟五爻（卦主）遥相呼应。

这爻说的是：**选对了合作对象，而且关系是内生的、自然的，不是硬凑的，就吉。**

很多人合作是"被合作"——别人拉你，你不情愿但又不好意思拒绝。这种合作一定走不远。

比卦的"自内"，是说你**发自内心地认同这个合作**。不是被说服，不是被裹挟，是真正觉得"这个人/这个事，我愿意跟他一起做"。

跟对人是本事，心甘情愿跟对人是更大的本事。

## 三爻：别跟不该跟的人合作

六三：**比之匪人。**

跟不对的人合作。

这爻没有断吉凶，但"匪人"两个字已经很重了——**你在跟谁站在一起？**

现实生活中，这个问题比大多数人意识到的更重要。

你加入的公司、你合作的伙伴、你混的圈子——**这些人的水平，就是你的天花板。**

很多人不怕吃苦，不怕加班，但从来没想过一个问题：**我正在跟谁一起吃苦？**

吃苦跟对的人吃苦，吃的是经验。跟错的人吃苦，吃的纯粹就是苦。

六三爻是给所有正在选队的人敲的警钟：**别急。宁可慢一点，别站错队。**

## 四爻：主动找对人

六四：**外比之，贞吉。**

向外寻找合作对象，吉。

六四是上卦的初爻，紧挨着九五（卦主）。它"外比"——不是等别人来找自己，而是**主动向外去建立联系**。

跟初爻的"有孚"和二爻的"自内"不同，四爻说的是**主动出击**。

有些人等合作等到花儿都谢了，觉得"是金子总会发光"。比卦说：不一定。**金子也得让人看到才行。**

四爻的位置好——紧挨着核心。它告诉我们：**找到关键人物，主动靠近，关系对了就吉。**

但前提是"贞"——动机要正。不是拍马屁，不是攀附，是真正认可对方的价值，愿意跟他一起做事。

## 五爻：核心位置的担当

九五：**显比。王用三驱，失前禽，邑人不诫，吉。**

九五是比卦唯一的阳爻，是全卦的核心。

"显比"——光明正大地合作。不藏着掖着，不搞小圈子，让所有人都看得到。

后面那个比喻极其精彩："王用三驱，失前禽"——古代天子打猎，三面驱赶猎物，留一面让它们逃跑。**跑掉的就让它跑，不追。**

这是在说一个高级的管理哲学：**你要的是自愿追随你的人，不是被逼着留下来的人。**

跑了的，不追。因为追回来的人也不会真心跟你。

"邑人不诫，吉"——身边的人不用提醒，自然就守规矩。因为你的合作方式是公开透明的，大家心服口服。

五爻是比卦的核心：**真正的领导力不是控制，是吸引。让愿意跟你的人留下，让不愿留的人离开。留下的才是真盟友。**

## 上爻：合作的尽头——孤独

上六：**比之无首，凶。**

合作到了最后，没有领头人，凶。

上爻是比卦的最顶端，已经没有爻再往上呼应了。它"无首"——找不到可以依靠和追随的核心。

这爻说的是：**如果你要合作的对象本身就没有方向，那你加入进去也等于零。**

一群没有头羊的羊群，只会互相踩踏。

换个角度读：上爻也在警告那些一直"跟队"的人——**如果你从头到尾只是跟，从来没有建立自己的判断力，一旦领头人倒了，你就什么都剩不下。**

合作不是放弃思考，是**带着脑子选队，带着判断力做事**。

## 比卦的现实应用

比卦的智慧放在现代生活里，四条：

1. **合作看诚意**——不是算计谁占便宜，是拿出真东西，诚意满到溢出来。
2. **别跟错人**——你跟的人的水平，就是你的天花板。宁可不合作，不跟错队。
3. **主动出击**——等不来合作，就去找。找到了关键人物，主动靠近。
4. **留住自愿的，放走不情愿的**——追回来的人不会真心，不追反而赢得尊重。

师卦讲的是怎么把人组织起来做事。比卦讲的是怎么找到对的人、建对的关系。

师卦是**硬实力**，比卦是**软实力**。

一个会用人的老板，和一个让人愿意追随的老板，是两种境界。比卦追求的是第二种——**不是让人不得不服从，是让人心甘情愿站在一起。**
