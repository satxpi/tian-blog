# 闲聊易经｜07坤卦：大地从不争，但它承载了一切

乾卦讲的是天，讲的是往上冲的力量。坤卦讲的是地，讲的是往下沉的容量。

这两个卦是六十四卦的门口。先乾后坤，先天后地。上一章说乾卦的核心是"自强不息"，这一章说坤卦的核心是"厚德载物"。一句话概括两卦的关系：**乾给你方向，坤给你根基。**

光有乾没有坤，人就是一匹脱缰的马，跑得快但不知道跑向哪里。光有坤没有乾，人就是一片沃土，肥是肥了，但长不出东西。

所以乾坤必须一起看。

## 卦象：全是阴

坤卦长这样：

```
上爻 ━ ━
五爻 ━ ━
四爻 ━ ━
三爻 ━ ━
二爻 ━ ━
初爻 ━ ━
```

六根全是阴爻，中间断裂。纯阴之卦。

阴代表柔顺、承载、被动、包容。乾卦的阳爻是实心的，像一根棍子，有力量往外顶；坤卦的阴爻是断开的，像两条平行线，有空间往里收。

这个区别很重要。**阳的力量是"去做"，阴的力量是"能装"。**

一个杯子，阳是它的形状，阴是它的容量。杯子之所以能装水，不是因为它的外壁有多硬，而是因为它中间是空的。坤卦教的就是这种"空"的智慧。

## 卦辞：元亨，利牝马之贞

坤卦的卦辞比乾卦长一些，有几个关键点。

**元亨**——同样是开始、通达。乾有元亨，坤也有元亨，说明天地之功是一样的，只是方式不同。乾以刚健通达，坤以柔顺通达。

**利牝马之贞**——这一句很特别。"牝马"是母马。为什么不直接说马？因为公马的特点是刚烈、好斗、不受约束，而母马的特点是柔顺但坚韧，能走远路，能驮重物，不会瞎冲。

坤卦告诉你：坤的"贞"，不是什么正道都适合，而是**要像母马一样**——顺从而有方向，柔韧而不软弱。母马跟马群走不会掉队，但自己也有足够的力气走完该走的路。

**先迷后得主**——先迷失方向，后来找到主人。这是坤卦给所有人的提醒：坤的定位是追随，不是领航。你一开始如果试图自己拿主意，会迷路。等你找到该跟随的方向，就稳了。

这不是贬低坤。这就像地永远不跟太阳争谁发光，但地知道自己该做什么——承载万物。**找准自己的位置，比争着往前冲重要。**

## 象传：地势坤，君子以厚德载物

乾卦的象传是"天行健"，坤卦的象传是"地势坤"。

天是动的，天行健，所以君子要自强不息。地是静的，地势坤，所以君子要厚德载物。

**厚德载物**这四个字跟"自强不息"一样出名，它们是一对。

什么叫"厚德"？不是说你品德高尚就是厚德。坤卦说的"厚"是大地的那种厚——泥土、岩石、矿物、水脉，层层叠叠，深不见底。大地的德行不在于它有多干净、多高尚，在于它能**承受**。

垃圾倒在土地上，土地不会拒绝。洪水冲过来，土地不会跑。种子掉进去，它就给你长出来。毒药泼上去，它慢慢分解净化。

大地的承受力，就是坤卦要你学的东西。

**载物**——不是"载好物"，是"载万物"。好的坏的，喜欢的讨厌的，顺境逆境，全都接着。这不是认怂，这是容量。

现实中很多人理解反了。觉得自己应该像乾卦，永远往上冲。但世界上的事不是都靠冲能解决的。有时候你需要的不是更强的力量，而是更大的容量。

一个团队里，乾卦型的人冲锋，坤卦型的人兜底。两种人缺一不可。

## 六爻：从脚下到天边

坤卦的六爻讲的是一个人作为"追随者""承载者"的成长路径。

### 初爻：履霜，坚冰至

**履霜，坚冰至。**

脚踩到霜了，就知道冰冻三尺的日子要来了。

这是坤卦最有预见性的一爻。霜是小信号，坚冰是大趋势。聪明的人不需要等到河面结冰才准备过冬的事，看到霜就知道冬天来了。

放在生活里：你的身体开始出小毛病了，这就是霜。如果不理，大病就是坚冰。你的项目开始出现小问题，这就是霜。如果不处理，大崩溃就是坚冰。

**初爻教的是预判力。不是等事情发生了再应对，是从小信号里读出大趋势。**

坤卦把这个放在第一爻很有深意——预判是坤的基础能力。承载者的前提是能看见远处的事，提前准备。

### 二爻：直方大

**直、方、大，不习无不利。**

三个字：直、方、大。

**直**——正直，不拐弯抹角。坤卦虽然是阴柔的，但不是让你圆滑世故。直是坤的品质：大地就是直的，你往哪个方向走都是平坦的，它不会故意坑你。

**方**——方正，有原则。大地有边界，有规矩。山川河流有它自己的位置，不会乱来。方不是说死板，是说有原则、有底线。

**大**——格局大，胸怀大。大地之大，不在于面积，在于它什么都装得下。

"不习无不利"——不用刻意练习，自然就不会有害。直、方、大不是学来的技巧，是坤卦本来的气质。你只要真实、有原则、格局够大，自然不会吃亏。

**二爻是坤卦的核心爻位。做好了这三件事，后面都稳。**

### 三爻：含章可贞

**含章可贞，或从王事，无成有终。**

有才华，但藏起来，不显摆。

"含"是含着，"章"是文采、才华。你肚子里有东西，但不急着往外倒。

很多人觉得有才华就要让人知道。坤卦说：先别急。你的才华是你的，不需要通过别人的认可来证明。到了该用的时候自然用得上。

"或从王事"——跟着做大事。坤是追随者，你跟着一个对的方向走，帮着把事情做成。

"无成有终"——最后事情成了，但你不要居功。事情有好的结果就行了，不一定要你的名字在上面。

这句话在职场里特别实用。你帮老板把项目做成了，不用非得让所有人都知道是你做的。坤卦的智慧是：**做了事情不需要所有人都看见，结果好就行。**

这不是卑微，是格局。

### 四爻：括囊，无咎无誉

**括囊，无咎无誉。**

把口袋扎紧，不说话，不出头。

括是扎口，囊是口袋。把袋口收紧，里面装的东西不露出来。

这一爻的位置很有意思。四爻已经到了上卦，接近决策层了。在乾卦里，四爻是"或跃在渊"，可以往上冲。但在坤卦里，四爻的 advice 是**闭上嘴**。

为什么？因为坤的定位是承载，不是主导。你到了一个很高的位置，但你的角色还是坤，不是乾。这时候最容易犯的错就是觉得"我到这里了，该我说话了"。

坤卦说：不，你的任务还是承载。扎紧口袋，做好本职，不争功也不惹事。

"无咎无誉"——没有过错，也没有赞誉。看起来很平淡，但在某些时刻，**不出事就是最大的成就。**

### 五爻：黄裳，元吉

**黄裳，元吉。**

穿黄色的下衣，大吉。

黄是中央的颜色，代表中道。裳是下衣（上衣叫衣，下衣叫裳）。穿黄色的下衣是什么意思？

**你身处高位，但保持低位的心态。**

五爻是坤卦最高的好位置。但你穿的是裳——下衣，不是冠——帽子。你用中央的颜色（黄），代表你守中道、不偏激。你穿下衣，代表你不往上争。

一个位置很高的人，心态还在下面，这是坤卦最推崇的状态。

对比乾卦的五爻"飞龙在天"——那是光芒万丈、万人仰望。坤卦的五爻不一样，它不张扬，但它是最吉的一爻。

为什么？因为坤的本色就是承载。你越是退、越是让、越是不争，在坤卦的体系里反而越吉利。

**这爻的智慧可以翻译成一句话：越有本事的人越不需要证明自己有本事。**

### 上爻：龙战于野

**龙战于野，其血玄黄。**

龙在旷野上打起来了，流出来的血是黑黄色的。

乾卦的最后一爻是"亢龙有悔"，坤卦的最后一爻更猛——直接开打了。

这一爻讲的是坤走到极端会怎样。坤本来是柔顺、承载的，但如果坤做得太过，阴气太重，就会跟阳发生冲突。两条龙打起来，血流成河。玄是天的颜色（黑），黄是地的颜色（黄），天地的血混在一起，说明冲突已经到了不可调和的地步。

这一爻是对所有"坤型人格"的警告：**你可以退，但不能退到没有底线。你可以让，但不能让到别人踩在你头上。**

大地平时承载万物，但地震的时候大地也会发怒。坤卦告诉你：承载是有极限的。

## 坤卦讲了一件什么事

从履霜到龙战于野，坤卦讲了一个承载者的完整生命周期：

1. **履霜**——看远，从小信号预判大趋势
2. **直方大**——正直、有原则、格局大
3. **含章**——有才华但不显摆，做了事不居功
4. **括囊**——该闭嘴就闭嘴，不出事就是成就
5. **黄裳**——身处高位但保持低位心态
6. **龙战**——退让有底线，过了极限就反击

坤卦最大的误解是"坤就是弱"。不是。坤是另一种强。乾的强是打出去的力，坤的强是接得住的力。你可以一拳打碎一面墙，但你接不住地震。大地能接住。

最后回到那八个字：**自强不息，厚德载物。**

乾坤合在一起，才是完整的人格。光冲不行，光忍也不行。该冲的时候有乾的劲，该忍的时候有坤的量。这就是易经前两卦给所有人的第一课。
