# 闲聊易经｜08屯卦：万事开头难，但开了头就好走

乾卦讲往上冲，坤卦讲稳得住。屯卦讲什么？讲**动弹不得**。

乾坤两卦之后，第三卦就是屯。屯的意思是"刚生出来的小苗"，想往上长，但被土压着，被石头挡着，费好大力气才能冒个头。

所以屯卦的核心就四个字：**万事开头难。**

这一卦告诉你，不是你不行，是开头本来就难。做好心理准备，慢慢磨，能过去的。

## 卦象：雷在水中

屯卦长这样：

```
上爻 ━ ━
五爻 ━━━
四爻 ━ ━
三爻 ━ ━
二爻 ━ ━
初爻 ━━━
```

上卦是坎，水。下卦是震，雷。**雷在水下面响，这叫屯。**

这是个很形象的卦。雷本来应该在天上打，现在被压在水底下。能量憋着，想爆发，发不出来。水又重又沉，把雷的情绪全困住。

换成生活场景就是：你有一个想法，很好，很有能量。但你周围的环境、资源、时机全都constraint着，让你动不了。你想干，干不了。想走，走不了。

新公司刚成立，资金链紧张，人手不够，客户不认——这是屯。新项目刚启动，流程没通，阻力一堆，每一步都卡——这也是屯。

屯不是不好的卦。屯是**必然经历的阶段**。任何新事物诞生，头一关都是屯。婴儿出生要挤过产道，种子发芽要顶破泥土。没有屯，就没有后面的一切。

## 卦辞：元亨利贞，勿用有攸往

屯卦的卦辞开头四个字跟乾卦一样：**元亨利贞**。

这不是敷衍，是说屯卦不是坏卦。虽然难，但底子是好的。"元"是开始，"亨"是通达，"利"是有利，"贞"是正道。这四个字本来应该写在顺顺利利的卦上，易经把它放在屯卦里，意思是：**难归难，方向是对的。**

后面跟了一句：**勿用有攸往，利建侯。**

"勿用"不是躺平，是说别乱动作。你现在的状态是被困住的，硬冲只会撞墙。缓一缓，稳一稳，先把自己理清楚。

"利建侯"——适合建立根基、找帮手。屯卦这时候，最重要的是**搭班子、建地盘、找盟友**。不要急着往前冲，先把脚下站稳。

很多人理解反了。觉得这是开头，得使劲冲。恰恰相反，屯卦告诉你：你现在冲不动，先蹲下来把马步扎好。

## 象传：云雷屯，君子以经纶

象传说：**云雷屯，君子以经纶。**

云是坎卦的象，雷是震卦的象。云在天上压着，雷在地下憋着，这就是屯。

"经纶"两个字什么意思？经是织布的经线，纶是青色的丝线。合起来是编织的意思。

古人说"经纶"是说治国理政，但本义是"整理乱麻"。屯卦讲的就是把这团乱麻理清楚。

你在屯的阶段，周围全是乱的——信息乱、关系乱、资源乱、思路乱。君子要做的，不是抱怨乱，而是**一点一点理出头绪**。

经纶是慢活。你不能扯，一扯就断。你得一根一根找，找到头，顺下去，再找下一根。

现实里：项目启动阶段一团乱麻，你天天加班也没用。这时候需要的不是更努力，而是更耐心——梳理流程，确定优先级，一个一个解决。

## 六爻：从被困到走出

屯卦的六爻，讲的是一个人从"被卡住"到"终于能走"的过程。

### 初爻：磐桓，利居贞

**磐桓，利居贞，利建侯。**

磐是大石头，桓是徘徊。你面前有块大石头，绕不过去，你在那儿来回走，不知道该往哪边。

这是屯卦的开始。你刚上路，就碰到大障碍。

"利居贞"——这时候适合待在原地，别乱跑。不是放弃，是**观察**。石头挡着，你硬撞过去会撞死。先停一停，看看有没有别的路，或者等石头自己松一松。

"利建侯"——找帮手。一个人搬不走大石头，几个人一起可能就行。建侯就是找盟友、找团队、找资源。

**初爻的智慧：别硬冲，先稳住，再找人。**

### 二爻：屯如邅如

**屯如邅如，乘马班如，匪寇婚媾。女子贞不字，十年乃字。**

这一爻很长，画面感很强。

"屯如邅如"——走不动，转来转去。往前走一步，退两步。原地打转。

"乘马班如"——骑在马上，马也在徘徊。马是动物，本来该跑的。现在马都犹豫了，说明连本能都在告诉你：现在不是冲的时候。

"匪寇婚媾"——远处来了一群人，你以为是强盗，结果发现是来求婚的。

这是屯卦最有意思的一爻。你以为要出大事，结果是个误会。你以为天要塌，结果那是有人来帮你。但这个"帮"来得很慢。

"女子贞不字，十年乃字"——女子一直不生孩子，十年才生。

翻译成白话：**你以为的灾难可能不是灾难，你以为的希望来得比想象中慢。**

这一爻专门治急性子。你着急，没办法，十年就是十年。好事会来的，但不是今天。

### 三爻：即鹿无虞

**即鹿无虞，惟入于林中。君子几不如舍，往吝。**

你追一只鹿，但没带向导（虞），追着追着进到树林深处，迷路了。

这一爻是警告。你在屯卦的阶段，欲求心会很强——想快点挣脱困境，想快点看到成果。但欲速则不达。

"君子几不如舍"——君子与其勉强追，不如放弃。鹿跑了就跑了，你进去几步找不到路，再往里走就是被困。

"往吝"——继续追下去，会后悔。

**三爻的智慧：有些东西追不到就算了，别把自己赔进去。**

这正是屯卦最常出现的心态——因为被困久，特别想抓住点什么来证明自己在前进。但这时候最该做的是分辨：什么值得追，什么是幻觉。

### 四爻：乘马班如

**乘马班如，求婚媾，往吉，无不利。**

又是骑马徘徊。但这时候不一样了——"求婚媾"。

你的方向从"追鹿"变成了"求婚"。追鹿是追猎物，是单方面的欲望。求婚是找伙伴，是双向的关系。

前面三爻你都在自己挣扎——撞石头、原地转、追鹿迷路。到四爻，你终于明白：我一个人搞不定，我得找人。

"往吉，无不利"——去求，吉利，不会不利。

**四爻是转折点。从单打独斗转向寻求合作。**

屯卦告诉你：被困住的问题，靠困住你的那个人是解不开的。你得找别的人、别的资源、别的视角。你开公司开不下去，找合伙人。你项目卡住，找前辈请教。你身体出问题，找医生。

求助不是认输，是破屯的方法。

### 五爻：屯其膏

**屯其膏，小贞吉，大贞凶。**

膏是油脂、肥肉，引申为资源、财富。"屯其膏"——把资源囤起来，不往外发散。

这一爻开始有点松动了。你已经不是完全被困住的状态，你手里开始有点东西了。但这时候要克制，不要急着撒出去。

"小贞吉"——小事可以慢慢做，有起色。大贞凶——大事这时候做，会出问题。

为什么？因为你在屯卦里永远是受限的。你攒了点钱，不要觉得可以大展宏图。你有点突破了，别觉得可以放手一搏。**你的突破只是小突破，不是大翻身。**

很多人在四爻找到帮手、五爻攒了点资源之后就飘了，觉得苦日子过去了。没有。屯卦的凶险就在于你以为结束了，其实只是中场休息。

**五爻的智慧：小有突破时，不要做大决定。**

### 上爻：乘马班如，泣血涟如

**乘马班如，泣血涟如。**

最后一次骑马徘徊，但这次不一样——"泣血涟如"。

泣血是哭到出血。涟如是一滴滴往下流，停不住。

上爻是屯卦的结果，有两种可能。

第一种可能：你从初爻到五爻，每一步都听进去了，没有乱动，慢慢找路，慢慢攒资源，到上爻终于——还是很难，但你认了。你知道开头难，十几年后也许能春天。这叫"泣血涟如"，是对命运的理解，不是认命。

第二种可能：你没听进去，每个爻都试探着来，撞了石头继续撞，追鹿追丢了自己，有资源就挥霍。到上爻，你把所有机会都耗光了，骑在马上，哭到出血。

屯卦的上爻，不告诉你结局好坏。它只告诉你：**这一路你走成什么样，最后心里都清楚。**

用正确的方式走屯卦，泣血是释然的泪、是扎根的泪。用错误的方式走屯卦，泣血是后悔的泪、是浪费的泪。

## 屯卦讲了一件什么事

从磐桓到大石，从追鹿到求婚，从屯膏到泣血，屯卦讲的是万事开头难的完整心法：

1. **磐桓**——碰到大石头，先站稳，别硬冲
2. **屯邅**——着急没用，好事来得比你想象中慢
3. **追鹿**——别被欲求带节奏，有些东西追不到就算了
4. **求婚**——一个人搞不定，找帮手
5. **屯膏**——有点突破别飘，小做小吉，大做大凶
6. **泣血**——走完这一路，你会清楚自己走成什么样

屯卦的本质不是吓你。屯卦的本质是告诉你：**开头难是正常的，不要因为开头难就觉得自己不行。**

任何值得做的事，开头都要经历屯的阶段。小苗要顶破泥土，婴儿要挤过产道，项目要理清乱麻。这不是你不行，这是所有新生命的必经之路。

所以屯卦卦辞给你四个字：元亨利贞。

开头难，但底子是好的。撑过去，后面自然亨通。
